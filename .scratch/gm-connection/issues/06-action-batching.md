# 06: 행동 묶기 (모음 창)

**What to build:** 여러 플레이어가 몇 초 안에 보낸 행동과 도착 이벤트를 한 묶음으로 GM 턴 한 번에 넘긴다. GM은 캐릭터별 행동을 한 장면으로 서술한다. 스펙: `../spec.md` "턴 조율".

**Blocked by:** 01, 05

**Status:** ready-for-agent

- [ ] 큐가 비어 있을 때 첫 입력이 들어오면 모음 창(기본 4초, 설정 가능)이 시작된다
- [ ] 창이 닫히면 쌓인 입력 전부가 턴 한 번으로 간다
- [ ] 턴 도중 들어온 입력은 다음 묶음이 된다
- [ ] 모음 창이 열려 있는 동안에도 `pending`이 켜진다 (04와 함께 쓰면 표시됨)
- [ ] 가짜 시계 + `ScriptedProvider` 세션 테스트: 묶음, 턴 도중 입력, 연속 턴
