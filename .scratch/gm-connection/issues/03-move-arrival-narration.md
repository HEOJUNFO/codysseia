# 03: 명확한 이동 → GM 도착 서술

**What to build:** 이동 버튼이나 장면 지도로 이동하면 엔진이 바로 옮기고, 도착 이벤트(`location_entered`, 첫 방문 여부)를 GM 턴에 넘겨 도착 묘사를 받는다. 섬 간 이동이면 항해 이벤트(`voyage`, 출발·도착 섬, 걸린 시간)도 함께 넘겨 뱃길을 먼저 서술하게 한다 (대전제 8.6 "항해"). `GameRoom`의 가짜 도착·항해 문장(`#arrival`, `#applyEvents`)은 없앤다. 첫 방문은 자세히, 재방문은 짧게 묘사한다. 스펙: `../spec.md` "턴 조율".

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 이동 응답은 GM을 기다리지 않는다. 위치 변경이 먼저 발행되고 서술은 뒤에 붙는다
- [ ] 도착 이벤트가 GM 턴 입력에 첫 방문 여부와 함께 들어간다
- [ ] 섬 간 이동이면 항해 이벤트가 걸린 시간과 함께 GM 턴 입력에 들어간다
- [ ] 방 시작 때의 첫 도착도 같은 경로로 서술된다
- [ ] "(가짜 GM)" 도착·항해 문장이 더 이상 나오지 않는다
- [ ] `/move <섬_id>` 개발 명령은 GM을 거치지 않는다
- [ ] 방 테스트: 이동 → 상태 즉시 변경 → 도착 서술 로그
