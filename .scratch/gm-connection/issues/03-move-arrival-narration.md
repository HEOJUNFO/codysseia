# 03: 명확한 이동 → GM 도착 서술

**What to build:** 이동 버튼이나 장면 지도로 이동하면 엔진이 바로 옮기고, 도착 이벤트(`location_entered`, 첫 방문 여부)를 GM 턴에 넘겨 도착 묘사를 받는다. 가짜 도착 문장은 없앤다. 첫 방문은 자세히, 재방문은 짧게 묘사한다. 스펙: `../spec.md` "턴 조율".

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 이동 응답은 GM을 기다리지 않는다. 위치가 먼저 바뀌고 서술은 뒤에 붙는다
- [ ] 도착 이벤트가 GM 턴 입력에 첫 방문 여부와 함께 들어간다
- [ ] "(가짜 GM)" 도착 문장이 더 이상 나오지 않는다
- [ ] `/move <섬_id>` 개발 명령은 GM을 거치지 않는다
- [ ] 세션 테스트: 이동 → 상태 즉시 변경 → 도착 서술 로그
