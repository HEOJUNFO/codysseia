# 05: 방 코드 입장 + 캐릭터 고르기

**What to build:** 서버를 시작하면 방 코드가 호스트 콘솔에 나온다. 접속자는 입장 화면에서 방 코드를 넣고 비어 있는 캐릭터를 고른다. 선택은 서명한 쿠키에 남아 새로고침해도 유지된다. 행동 로그에는 누가 했는지 캐릭터가 붙는다. 방 코드가 없는 요청은 모두 거부한다. 스펙: `../spec.md` "방 입장과 신원".

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 방 코드는 시작할 때 만들어지고, `.env`로 고정할 수 있다 (`.env.example`에 키 이름 추가)
- [ ] 이미 다른 접속자가 고른 캐릭터는 고를 수 없다
- [ ] 쿠키 없는 상태 조회·행동·이동·SSE 요청은 거부된다
- [ ] 행동 로그 항목에 캐릭터 id가 있고, 화면에 캐릭터 이름으로 보인다
- [ ] GM 턴 입력의 행동에 캐릭터가 붙어 간다
