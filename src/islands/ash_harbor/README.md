# 잿빛 항구 (ash_harbor) — 예시 섬

새 섬을 만들 때 참고하는 예시다. 폴더째 복사한 뒤 `ash_harbor`를 내 섬 ID로 모두 바꾸고 내용을 채운다.
양식과 규칙은 [`docs/01_섬_제작_템플릿.md`](../../docs/01_섬_제작_템플릿.md)를 따른다.

## 파일

| 파일 | 필수 | 내용 |
|---|---|---|
| `island.yaml` | ✅ | 섬 기본 정보, 도착 지역, 군도 지도 위치 |
| `gm.md` | ✅ | GM 지침 |
| `locations/*.yaml` | ✅ (1개 이상) | 지역과 연결, 지점 |
| `web/page.tsx` | ✅ | 장면 화면 |
| `npcs/`, `monsters/`, `items/`, `events/` | | 섬 내용 |
| `hooks.yaml` | | 다른 섬에 공개하는 것 |
| `assets/` | | 이미지·소리 (지금은 임시 SVG) |

## 컨셉과 이야기

- **첫인상**: 안개 낀 부두. 멀리 불 꺼진 등대가 보이고 종은 울리지 않는다.
- **섬의 비극 / 갈등**: 종이 멈춘 뒤로 안개가 걷히지 않고, 물에 빠진 사람들이 돌아다닌다.
- **주요 목표**: 종을 다시 울린다 (`ash_harbor.flag.bell_rung`).
- **결말 분기**: 등대지기의 비밀을 알고 용서하면 등대에 불이 켜진다. 밝히지 못하면 종만 울리고 등대는 계속 어둡다.

## 지역 흐름

```
부두 ──> 무너진 시장 ──(열쇠)──> 등대
              └──(지도를 읽으면 드러남)──> 우물 밑 지하실
```
