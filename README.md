# 코디세이아 (Codysseia)

여러 제작자가 각자 만든 섬을 파티가 자유롭게 탐험하는 디지털 TRPG.
GM은 호스트의 Codex가 맡는다.

> 이름은 『오디세이아』에서 친구 별명 "코"를 따왔다.
